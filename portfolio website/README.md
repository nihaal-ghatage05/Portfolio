# Portfolio Website

A personal portfolio website for Nihaal Ghatage, built as a modern static landing page to showcase skills, projects, education, services, and contact information.

## Overview

This project presents:
- A responsive hero section and navigation
- About me and skills sections
- Project highlights with technology tags
- Education timeline
- Services and achievements
- Contact form section
- Dark/light theme toggle
- Smooth scroll and reveal animations

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Static assets (profile image and downloadable resume)

## Project Structure

- `index.html` — main portfolio page
- `profile.png` — profile image used in the hero section
- `README.md` — project documentation

## How to Run

You can view the site locally in either of these ways:

1. Open `index.html` directly in a browser.
2. Or run a local server from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- The portfolio is designed for a static web environment.
- If you want to include a resume file, place it in the project root and update the resume link in `index.html`.
- The site uses client-side JavaScript for theme switching, typing animation, and reveal effects.

## Customization

Update the content in `index.html` to:
- change the personal bio
- add or remove projects
- update links to GitHub, LinkedIn, and email
- modify colors, fonts, and sections based on your preference
